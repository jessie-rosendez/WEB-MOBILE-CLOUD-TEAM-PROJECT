# Phantm BTE400 Project

This repo is the working starter for the Spring 2026 BTE 400 group project.

Current project direction:
- Category: `Gaming & Accessories`
- Brand: `Phantm`
- Catalog strategy: keep exact Razer product names on the site for now
- Signature product: `Phantm Spectre X` racing-style chair
- Group size: `5 people`

Why the repo is structured this way:
- `index.html`, `styles.css`, and `script.js` hold the live website prototype because the storefront is the most visible part of the project.
- `docs/checklist.md` exists to keep the team aligned on what is done versus what still needs work.
- `docs/agent-knowledge-base.md` exists so support-agent content is not trapped only inside the front-end code.
- `docs/cloud-forecast-starter.csv` exists so the forecast can move into Excel quickly with less retyping.
- `docs/kickstarter-preview.md` exists so the campaign draft has a clean home outside the homepage copy.
- `docs/scrum-plan.md` exists so sprint planning and role rotation are easy to track.

Recommended working order:
1. Finalize the website copy and visuals.
2. Expand the agent knowledge content.
3. Move the cloud forecast CSV into Excel and build the graph.
4. Refine the Kickstarter preview and pitch script.
5. Use the Scrum doc to assign owners and sprint goals.
