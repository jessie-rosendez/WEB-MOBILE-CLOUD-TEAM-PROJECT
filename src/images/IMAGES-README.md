# Product Images

Drop images into this folder (`src/images/`) with the exact filenames below.
Both the store cards and individual product detail pages will pick them up automatically.
If an image is missing, the SVG icon placeholder shows instead — so the site never breaks.

Supported formats: `.jpg` (preferred), `.png`, `.webp`

- Images should have Phantm branding visible, not Razer.
- Recommended size: 800×600px or larger, transparent or dark background.
- The store card uses the same image as the product detail page.
